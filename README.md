# backfun

Сайт без сборки: чистый HTML/CSS/JS, подходит для GitHub Pages.

## Где что менять
- `js/data.js` - все тексты, цифры, ссылки и данные сезонов Медсана (там же список того, что ещё не заполнено).
- `images/` - выбранные обложки и фотографии сезонов, список файлов в `images/README.txt`.

## Новый сезон
1. Добавить объект в `seasons` в `js/data.js` (с новым `id`).
2. Скопировать папку `madsun/3` в `madsun/4`, поменять в ней `data-season="3"` на `4` и номер в `<title>`.
3. Положить `cover.jpg` и фотографии `1.jpg`, `2.jpg` ... в `images/madsun/4/`.

## Локальный просмотр
Пути абсолютные (`/css/...`), открывать надо через сервер, а не двойным кликом:
`python -m http.server 8000`, затем http://localhost:8000
Вид карточки Twitch во время стрима: `/?live=1`, без стрима: `/?live=0`.
